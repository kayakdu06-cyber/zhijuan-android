# V9 CR25–28 实施计划

## 基线与根因

- 三模块、四顶级路由、单 Provider 协议、单活动任务和普通章两调用边界保持不变。
- 返回循环根因：阅读页和生成页分别把对方记为返回来源，互相跳转后来源也互相指向。
- 旧书没有剧情节奏字段；必须以兼容默认迁移，不批量重写项目文件。
- “沉浸”已有成年题材分档，但提示词容易被模型以暗示、淡出或概括代替关键过程。

## 实施顺序

1. 以可保存的有限返回栈取代双向来源指针；目标已是直接父层时弹栈，底栏顶级切换清栈。

3. 将剧情节奏注入当前章任务，强制当章目标、因果、情绪和身体连续性；节奏不得跳过计划项或提前消耗未来事件。
4. 加强“沉浸”内部规则：成年任务明确要求时，直接、完整、连续落笔，保持空间、动作、感官、自愿/非自愿事实与后果连续，不用淡出或事后概括代替关键情节。
5. 底部导航内容整体下移 `6dp`，保留原高度、系统导航区适配和触控区。
6. 执行 JVM、Android instrumentation、lint、debug/release、模块边界、安全与备份门禁；安装 release 到实体手机。
